Benchmarks

Two benchmarks other projects publish, run with foil as the sandbox and compared on the same machine: how fast, how easy to set up, and what each leaves behind.

Measured 2026-11-03 on a 4-vCPU Lima VM (Ubuntu 26.04, Linux 7.0) on an Intel Mac, foil 0.4.0. Scripts, raw results and caveats: bench/opensandbox-method, bench/sandboxfusion.

OpenSandbox's create benchmark: Docker vs foil

OpenSandbox's own create-bench.py, through its unchanged Python SDK, against OpenSandbox's server with its Docker runtime and against foil serve. Time is from the create call to the sandbox answering /ping; 100 creates per row. Each foil sandbox is a branch of a 6,000-file Django checkout; each Docker sandbox is an empty ubuntu:24.04.

  • Left behind: 83 running Docker containers, from creates that passed the SDK's 10-second timeout but which the server finished anyway; foil left nothing.
  • Setup: Docker needs a root daemon, about 300 MB of images, a Python server and a config file; foil needs one 3 MB binary and foil serve -w DIR.
  • Not compared: OpenSandbox's Firecracker fast-sandbox (64 ms median on a 192-CPU cluster), which gives each sandbox its own kernel, a much stronger boundary than foil's.
  • A foil weakness this found: start times grow with how many start at once, because each sandbox waits for its own systemd scope. A fix is planned.

SandboxFusion: its own sandbox vs foil

ByteDance's SandboxFusion runs model-written code for HumanEval, MBPP and similar evaluations. Its lite sandbox is built as root from an overlay of /, cgroups, a network namespace and chroot. We added a 24-line foil mode that runs as an ordinary user, and sent all 164 HumanEval solutions through each mode. All 164 passed everywhere.

SWE-bench Verified: a real agent, with and without foil

Claude Code (Opus 5.5) on 50 SWE-bench Verified tasks (Django and sympy), three runs per arm: bare claude -p, and foil agent claude in strict mode (no home contents, network only to api.anthropic.com through foil's proxy, which holds the key), then foil commit. Hidden tests run outside foil afterwards.

run 1run 2run 3mean
without foil43 / 5044 / 5041 / 5042.7
with foil (strict)41 / 5043 / 5042 / 5042.0

The ranges overlap, and the median agent time was 17 s in both arms. Under foil, the real workspace stayed unchanged until commit in 150 of 150 runs, every commit succeeded, the API key never appeared in the agent's output, and nothing the agent tried was refused. Five tasks went unsolved in every run of both arms.

Measured 2026-11-08, same VM, foil 0.5.0 with PR #16, Claude Code 2.1.302, $29.57 in API cost. The VM's clock was stabilized for the run (one time service, not two); the results say how and why. Per-task outcomes and raw JSONL are there too.
